## 重要声明

### 关于「不满人数」

本数据集给出的是**可逐条核实的下限**，不是精确真值。

- **判定受 AI 语义理解能力限制**：反讽、圈内黑话、纯表情无法完全识别
- **未识别 ≠ 满意**：7,342 个「中立」中，约 10% 抽样仍可能是冲官方
- **排期抱怨按用户要求计入中立**，不计入冲官方

### 关于原始数据

出于体积考虑，本仓库**不包含** 70MB 的原始全量 JSON（`full_pv.json`，128,952 条原始评论）。

如需原始数据，可运行 `scripts/01_spider.py` 重新抓取（约 11 分钟）。

### 数据用途

本数据集用于公开的舆论分析研究，所有数据均来自 B 站公开评论接口，不含任何用户隐私信息（仅含公开的 mid、昵称、评论内容、时间、点赞数、IP 属地）。

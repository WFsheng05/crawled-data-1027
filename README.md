## 五、方法论要点

### 双口径强制并报（SOP v1.1）

**只报一个口径会误导。** 立场结论必须同时给出：
- 按独立用户（一人一票）
- 按评论条数（原始声量）
- 附基尼系数、中位数发帖、只发一条占比

### 数据血缘规则（SOP v1.1）

**`stance_1028.csv` / `stance_rejudge.csv` 是唯一权威口径。**

中间文件（official_*、silver_repetition、hidden_neg 等）仅供过程追溯，**禁止直接引用数字**——存在标签污染风险（已由外部复核发现）。

### 判定流程

1. **规则初筛** → 覆盖明显表达
2. **10 个子代理逐条重判** 9,616 个中立用户
3. **校验**：10 批全部通过（无缺失、无重复、无错位）

### 已知局限

- **反讽**：「哪里弱了」「太有面子了」字面肯定、语境否定，只能逐条判
- **圈内黑话**：「超大上」「借过」「留了一手」需领域知识
- **未识别 ≠ 满意**：中立中仍有约 10% 抽样可能是未识别的批评者
- **无标注者间信度（Cohen's κ）**：8 批无重叠抽样，下一版须补

## 七、重要声明

### 研究性质

本研究为 **LLM 辅助内容分析**，立场判定含规则筛选 + 子代理逐条复核环节，**非严格意义上的标注科学研究**。

- 无 Cohen's κ 等标注者间信度指标
- 反讽、黑话的判定本质上不可完全证伪
- 报告数字是**可核实下限**，不是真值

### 原始数据

出于体积限制，本仓库**不包含** 111MB 的原始全量 JSON。

如需原始数据，运行 `scripts/01_spider.py` 重新抓取（约 20 分钟）。

### 数据合规

所有数据均来自 B 站公开评论接口，仅含公开的 mid、昵称、评论内容、时间、点赞数、IP 属地。不含任何私信或非公开信息。

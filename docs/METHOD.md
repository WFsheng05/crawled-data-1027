# 判定口径与方法论

本文档说明本数据集中「冲官方 / 支持官方 / 中立 / 无实质」四类标签的判定标准。

---

## 一、问题定义

### 为什么不用「评论数」

遇到节奏时，评论总量会被少数账号的单点放大严重污染：

- 261 个账号（1.6%）贡献了 55.8% 的评论
- 单人最高发帖 1,026 条
- 峰值小时 6,818 条

**因此「评论数」衡量的是声量，「用户数」衡量的才是人。** 本数据集按 `mid` 去重，一人一票。

### 分母

| 口径 | 人数 | 说明 |
|---|---|---|
| 全量用户 | 16,485 | 所有在本视频下发过言的 mid |
| 有实质表达 | 16,241 | 排除 244 个无实质内容用户 |

## 二、四类标签定义

### ① 冲官方（8,132 人）

批评、嘲讽、质疑**官方或游戏内容**。包括以下子类：

| 子类 | 示例 |
|---|---|
| 直接诉求 | 「加强塔露拉」「重做技能」「改机制」 |
| 强度批评 | 「打不过杰斯顿」「法穿缺失」「不如望」 |
| 机制批评 | 「启动慢」「绑配队」「损伤抢条」 |
| 设计批评 | 「断手」「立绘崩」「敷衍」「压稿」 |
| 剧情批评 | 「人设崩」「编剧吃书」 |
| 反讽 | 「太有面子了」「哪里弱了」「够强了」「还要什么自行车」 |
| 间接暗示 | 只提「陪跑」「借过」「留了一手」「又是本源近卫」 |
| 冲锋话术 | 「孝子」「洗地」「强度区」「捂嘴」「青蒜」 |
| 组织行动 | 「修墙」「砌墙」「填工单」「救救塔露拉」 |
| 直接辱骂官方 | 「鹰角不当人」「神人公司」 |

**关键：反讽必须识别。** 「哪里弱了」在批评语境下是反讽，不是肯定。

### ② 支持官方（767 人）

| 子类 | 示例 |
|---|---|
| 为设计辩护 | 「断臂很帅」「别的厂商不会这样做」 |
| 反对加强诉求 | 「够用了」「没必要加强」「强度没问题」 |
| 否定冲的正当性 | 「还没实装别急」「别带节奏」「游戏而已」 |
| 复读「银灰节奏复刻」 | 「又是一个银灰」「百万银灰厨复刻」 |
| 嘲讽冲动方 | 「百万塔厨」「评论区一堆僵尸」「饭圈打榜」 |

**关键：「银灰节奏复刻」类复读归入支持官方**，因为它是在嘲讽「这次又是老一套」，消解节奏的正当性。

### ③ 中立（7,342 人）

有发言，但**没有对官方表达任何立场**：

| 类别 | 人数 | 示例 |
|---|---|---|
| 其它零散短评 | 3,199 | 难以归类的短句 |
| 剧情考据/讨论 | 1,417 | 「黑蛇夺舍」「内卫考据」 |
| 纯表情/短句 | 744 | 「[汤圆]」「1」 |
| 纯提问 | 422 | 「手咋断的」「啥时候开卡池」 |
| 玩梗/接龙 | 405 | 「阿一古」「马头」「杨过」 |
| 许愿/抽卡 | 367 | 「许愿塔露拉，出必还愿」 |
| 夸PV/画面 | 328 | 「音乐好听」「画面震撼」 |
| 角色喜爱 | 327 | 「好帅」「心疼塔子姐」 |
| **排期抱怨** | **58** | 「好痛苦，一定要隔一周才开活动吗」 |
| 旁观/吃瓜 | 49 | 「不明真相的吃瓜群众」 |
| 宣群/引流 | 26 | 「友好老群，欢迎来玩」 |

**特别注意：排期/时间类抱怨一律判中立**（用户明确要求），不计入冲官方。

### ④ 无实质内容（244 人）

纯表情、纯数字、无法判断的极短内容，排除在分母之外。

## 三、判定流程

### 阶段 1：规则判定（`scripts/03_stance_rule.py`）

用关键词 + 结构化规则做初筛，覆盖明显的表达。

**局限**：反讽、圈内黑话、间接暗示容易漏判。

### 阶段 2：子代理逐条重判（`scripts/04_merge_agent.py`）

对规则判定为「中立」的 7,689 个用户，分成 8 批（每批约 960 条），由 8 个独立子代理**逐条人工语义判定**。

**每批判定后校验**：
- mid 与输入逐行对齐
- 无缺失、无重复
- 格式统一（`mid\t标签\t理由`）

**重判结果**：
| 批次 | A 冲官方 | B 支持官方 | C 无立场 |
|---|---|---|---|
| v1 | 87 | 62 | 813 |
| v2 | 19 | 8 | 935 |
| v3 | 10 | 3 | 949 |
| v4 | 15 | 5 | 942 |
| v5 | 38 | 36 | 888 |
| v6 | 6 | 28 | 928 |
| v7 | 0 | 14 | 948 |
| v8 | 13 | 3 | 939 |
| **合计** | **188** | **159** | **7,342** |

### 阶段 3：交叉验证（`scripts/08_verify.py`）

校验所有 mid 唯一性、格式完整性、与输入的一致性。

## 四、判定优先级

当一个用户同时有多种表达时，按以下优先级归类：

```
冲官方 > 支持官方 > 中立 > 无实质
```

**例外**：如果用户只有「银灰节奏复刻」类发言且无其他批评，归入支持官方。

## 五、已知局限

### 1. AI 语义理解的天花板

**无法可靠识别的类型**：

- **反讽**：字面是夸，意思是骂（「太有面子了」「这设计很可怕吗，是的」）
- **圈内黑话**：「超大上」「借过」「中杯」「青蒜」需领域知识
- **语境依赖**：同一句「欢迎上岛」可以是真心也可以是讽刺
- **纯表情**：「[汤圆]」「😅」单独一条，读不出态度

### 2. 抽样验证的误差

对中立用户随机抽样 50 条，人工判断发现约 5 条（10%）实为冲官方。

**这意味着**：7,342 个中立中，可能还有约 700 人是未被识别的冲官方。

**本数据集给出的是下限，不是真值。**

### 3. 未识别 ≠ 满意

**「中立」不等于「支持官方」。** 大量中立用户只是：

- 没参与讨论（只发表情、只提问）
- 讨论剧情/玩梗（与强度争议无关）
- 表达对角色本身的喜爱（不代表认可官方设计）

## 六、与「最严/最宽」口径的关系

本数据集采用**「最严」口径**（用户定义）：

> 只要客观上是在否定/嘲讽/质疑官方或游戏内容，就算冲官方。
> 包括间接暗示、反讽、单条轻吐槽——**要求一条不漏**。

这与常规理解的「最严」相反：**这里的「最严」是指判定标准最严苛，要求把每一条都识别出来，而不是收紧判定范围。**

### 如果采用「最宽」口径

按中立用户 10% 抽样比例外推：

| 口径 | 冲官方 | 支持官方 |
|---|---|---|
| 最严（可核实） | 8,132（49.3%） | 767（4.7%） |
| 最宽（含外推） | 约 8,870（53.8%） | 约 770（4.7%） |

## 七、数据来源与合规

- **接口**：B 站公开评论接口（`/x/v2/reply/main`、`/x/v2/reply/reply`）
- **抓取方式**：浏览器上下文 `fetch`（纯 HTTP 客户端会被指纹风控降级为 3 条）
- **采集时间**：2026-10-27
- **数据范围**：仅公开可见的评论内容、mid、昵称、时间、点赞数、IP 属地
- **不含**：任何私信、用户画像、非公开信息
